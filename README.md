# Práctica Android Studio

## Descripción

Proyecto desarrollado en Android Studio como parte de una práctica
académica para aprender el manejo de dependencias y control de
versiones utilizando Git y GitHub.

## Ficha técnica

- IDE: Android Studio
- Lenguaje: Kotlin
- SDK: Android SDK
- Minimum SDK: API 24
- Sistema de compilación: Gradle
- Configuración de Gradle: Kotlin DSL
- Control de versiones: Git
- Repositorio remoto: GitHub
